# ☁️ راهنمای نصب ذخیره ابری — اپلیکیشن لوازم برقی فانوس

این راهنما نحوه فعال‌سازی ذخیره ابری (Cloud Sync) را توضیح می‌دهد.

---

## 🎯 چرا ذخیره ابری؟

بدون ذخیره ابری، داده‌های شما فقط در مرورگر ذخیره می‌شود:
- ❌ اگر مرورگر را پاک کنید، داده‌ها حذف می‌شوند
- ❌ اگر از مرورگر دیگری وارد شوید، داده‌ها موجود نیستند
- ❌ اگر سیستم خراب شود، پشتیبانی ندارید

با ذخیره ابری:
- ✅ داده‌ها در سرور ابری ذخیره و پشتیبانی می‌شوند
- ✅ از هر مرورگر یا دستگاهی قابل دسترسی است
- ✅ همگام‌سازی خودکار هر ۶۰ ثانیه
- ✅ بدون اینترنت هم کار می‌کند (آفلاین) و بعداً همگام می‌شود

---

## 🚀 راهنمای گام به گام (Supabase — رایگان)

### گام ۱: ثبت‌نام در Supabase
1. به سایت [supabase.com](https://supabase.com) بروید
2. با ایمیل یا اکانت گوگل ثبت‌نام کنید
3. یک پروژه جدید بسازید (New Project)
   - نام پروژه: مثلاً `fanous-shop`
   - رمز عبور: یک رمز قوی انتخاب کنید
   - منطقه: ближайший منطقه را انتخاب کنید

### گام ۲: ساخت جدول داده‌ها
1. از منوی سمت چپ، **SQL Editor** را انتخاب کنید
2. کد SQL زیر را کپی و اجرا کنید:

```sql
-- جدول داده‌های دکان
CREATE TABLE shop_data (
    shop_id TEXT PRIMARY KEY,
    data JSONB NOT NULL,
    pin TEXT DEFAULT '',
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- فعال‌سازی دسترسی عمومی (با کلید anon)
ALTER TABLE shop_data ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow anon access" ON shop_data
    FOR ALL
    USING (true)
    WITH CHECK (true);
```

3. روی **Run** کلیک کنید تا جدول ساخته شود

### گام ۳: کپی اطلاعات اتصال
1. از منوی سمت چپ، **Settings** → **API** را انتخاب کنید
2. موارد زیر را کپی کنید:
   - **Project URL** = آدرس پروژه (مثل `https://xxxxx.supabase.co`)
   - **anon public** key = کلید عمومی (طولانی، شروع با `eyJhbGci...`)

### گام ۴: تنظیم در اپلیکیشن
1. اپلیکیشن فانوس را باز کنید
2. به صفحه **تنظیمات** بروید
3. در بخش **☁️ ذخیره ابری**:
   - نوع سرور: `Supabase` را انتخاب کنید
   - آدرس پروژه: URL مرحله ۳ را وارد کنید
   - کلید عمومی: anon key مرحله ۳ را وارد کنید
   - شناسه دکان: یک نام لاتین یکتا (مثل `fanous-kabul-1`)
   - رمز PIN: یک رمز ۴ رقمی انتخاب کنید
4. دکمه **☁️ اتصال به ابر** را بزنید
5. اگر اتصال موفق باشد، پیام تأیید نمایش داده می‌شود ✅

---

## 🔄 نحوه کار همگام‌سازی

- **هر بار داده‌ای ذخیره شود** → بعد ۳ ثانیه به ابر ارسال می‌شود (push)
- **هر ۶۰ ثانیه** → داده‌های ابری بررسی می‌شود (pull)
- **بدون اینترنت** → داده‌ها محلی ذخیره می‌شوند، بعد از اتصال مجدد همگام می‌شوند
- **تعارض** → آخرین نسخه برنده است (last-write-wins)
- **نشانگر وضعیت** در بالای صفحه:
  - ☁️ همگام‌شده = همه‌چیز به‌روز است
  - 🔄 همگام‌سازی... = در حال ارسال/دریافت
  - 📴 آفلاین = اینترنت ندارید
  - ⚠️ خطای اتصال = مشکل در سرور

## 🖥️ گزینه ۲: سرور سفارشی REST API

اگر سرور شخصی دارید، می‌توانید از API سفارشی استفاده کنید.

### مشخصات API:

```
PUT  /shop-data/:shopId
Body: { "data": {...}, "updatedAt": "ISO", "pin": "..." }
Headers: Content-Type: application/json, X-API-Key: your-key

GET  /shop-data/:shopId
Response: { "data": {...}, "updatedAt": "ISO" }
Headers: X-API-Key: your-key
```

### نمونه سرور Node.js:

```javascript
const express = require('express');
const app = express();
app.use(express.json({ limit: '10mb' }));

const store = {};

app.put('/shop-data/:shopId', (req, res) => {
    const { shopId } = req.params;
    store[shopId] = req.body;
    res.json({ ok: true });
});

app.get('/shop-data/:shopId', (req, res) => {
    const { shopId } = req.params;
    if (!store[shopId]) return res.status(404).json({ error: 'not found' });
    res.json(store[shopId]);
});

app.listen(3000, () => console.log('Cloud API on port 3000'));
```

## ❓ سؤالات رایج

### آیا رایگان است؟
بله! طرح رایگان Supabase شامل ۵۰۰ مگابایت فضای ذخیره‌سازی و درخواست‌های نامحدود API است.

### آیا داده‌ها امن هستند؟
داده‌ها با کلید عمومی (anon key) ذخیره می‌شوند. برای امنیت بیشتر، رمز PIN را فعال کنید. در آینده می‌توان احراز هویت کامل اضافه کرد.

### اگر دو دکان داشته باشم چطور؟
هر دکان باید شناسه (shop ID) متفاوت داشته باشد. مثلاً `fanous-kabul` و `fanous-herat`.

### اگر اینترنت قطع شود چطور؟
اپلیکیشن بدون مشکل کار می‌کند. داده‌ها محلی ذخیره می‌شوند و وقتی اینترنت برگردد، خودکار همگام‌سازی می‌شود.
