# لوازم برق و صنعت فانوس ⚡

یک اپلیکیشن تحت وب کامل برای مدیریت دکان لوازم برق و صنعت، تعمیرات، پروژه‌های برق‌کاری، کارمندان و امور مالی.

## ویژگی‌ها

- 📊 **داشبورد** - نمایش خلاصه فروش، تعمیرات، پروژه‌ها و موجودی کم
- 📦 **انبار و موجودی** - مدیریت محصولات، دسته‌بندی، قیمت و موجودی
- 🛒 **فروش و فاکتور** - ثبت فاکتور فروش با محاسبه خودکار و پرینت
- 🔧 **تعمیرات** - پیگیری دستگاه‌های مشتریان، وضعیت و هزینه تعمیر
- 🏗️ **پروژه‌های برق‌کاری** - مدیریت پروژه‌های منازل و شرکت‌ها با پرداخت‌های مرحله‌ای
- 👷 **کارمندان و شریک** - ثبت حقوق، پرداخت‌ها و سهم‌بندی
- 💰 **امور مالی** - گزارش درآمد، هزینه و سود
- 📥 **پشتیبان‌گیری** - خروجی و ورودی JSON

## نحوه استفاده روی GitHub Pages

1. یک ریپازیتوری جدید در GitHub بسازید
2. همه فایل‌های این پوشه را داخل ریپازیتوری پوش کنید (Push)
3. به Settings > Pages بروید
4. Source را روی Branch: main و Folder: / (root) تنظیم کنید
5. دکمه Save را بزنید
6. پس از چند دقیقه، سایت شما روی آدرس `https://username.github.io/reponame` در دسترس خواهد بود

> ⚠️ **نکته مهم**: این اپلیکیشن فقط با JavaScript کار می‌کند و داده‌ها در مرورگر (localStorage) ذخیره می‌شوند. برای پشتیبان‌گیری حتماً از دکمه "خروجی JSON" استفاده کنید.
